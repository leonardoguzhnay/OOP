# Sistema de Gestión de Inventario

## Descripción

Aplicación desarrollada en Python que permite administrar productos mediante Programación Orientada a Objetos.

## Objetivo

Gestionar productos permitiendo registrar, consultar, actualizar y eliminar información dentro de un inventario.

## Funcionalidades

- Registrar productos
- Buscar productos
- Listar productos
- Actualizar stock
- Eliminar productos
- Validar datos con Pydantic
- Herencia
- Polimorfismo

## Conceptos Aplicados

- Clases
- Objetos
- Atributos
- Métodos
- Encapsulación
- Herencia
- Polimorfismo
- Manejo de excepciones
- Modularización
- CRUD

## Instalación

```bash
pip install pydantic
```

## Ejecución

```bash
python main.py
```
